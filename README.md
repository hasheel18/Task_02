# 🎯 Task_02 - Java Mini Projects

This repository contains a collection of mini projects created using **Java** to strengthen my understanding of core programming concepts and problem-solving. 💻☕

## 📁 Projects Included

- **Banking Program**  
  A simple banking system for handling basic operations such as deposit, withdrawal, and balance checking.

- **Calculator Program**  
  A basic calculator that performs arithmetic operations.

- **Dice Roller Program**  
  A program that simulates rolling a dice and generating random results.

- **Number Guessing Game**  
  An interactive game where the user tries to guess a randomly generated number.

- **Temperature Converter**  
  A utility to convert temperatures between different units.

- **Weight Converter**  
  A converter for changing weight values between different measurement units.

## 🎯 Purpose

These mini projects were developed to gain a better understanding of the **Java programming language**, improve logical thinking, and practice fundamental programming concepts such as:

- Variables and data types
- Conditional statements
- Loops
- Methods
- Random number generation
- User input handling
- Basic object-oriented programming

## 🛠️ Technologies Used

- Java
- Console-based input/output
- IDE such as IntelliJ IDEA

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Task_02.git
   ```

2. Open the project in your preferred Java IDE.

3. Navigate to the required program folder.

4. Compile and run the `.java` file.

Example using terminal:
```bash
javac Main.java
java Main
```
